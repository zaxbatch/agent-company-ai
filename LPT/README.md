# LPT Realty — Filing & Approval Flow (IMPORTANT)

Everything in this folder is REAL ESTATE content. Zerric must approve it before
it can be sent or published anywhere. Never skip this step.

## The 3-Step Flow
1. **DRAFT** → Agent creates the file and saves it in `LPT/under-review/`.
   File naming: `[DRAFT] topic-v1.ext` (bump version on every revision).
2. **REVIEW** → Zerric reviews. Two outcomes:
   - ✅ APPROVED → file moves to the right subfolder below (marketing/, landing-pages/,
     property-management/, resources/) with the `[DRAFT]` prefix removed.
   - 🔁 CHANGES → Zerric leaves feedback; agent revises, bumps version to v2, v3...,
     and puts it back in `LPT/under-review/`.
3. **DONE** → Once delivered or superseded, move to `LPT/archive/`.

## Subfolders
- `under-review/`       → drafts WAITING for Zerric. Check here first.
- `marketing/`          → approved marketing material (KREC-compliant, EHO where required)
- `landing-pages/`      → approved page drafts
- `property-management/`→ approved property mgmt files (operates under LLC)
- `resources/`          → approved docs, templates, references
- `archive/`            → delivered/superseded files

## Hard Rules
- Every file must carry: brokerage name/address (LPT Realty), "Zerric Dotcom @ LPT Realty",
  and Equal Housing Opportunity statement where required.
- Z-Dot branding and LPT branding NEVER mix. Z-Dot work does NOT go in this folder.
- If unsure whether something is LPT or Z-Dot → ask Zerric before filing.
