# zerric.xyz — Improvement Plan (Trust Exercise)
Owner: NinjaNerd (CTO) + Mark · Date: 2026-08-24 · Status: PLAN READY — BossLady to approve scope

## What zerric.xyz is TODAY (verified live, 2026-08-24)
- Title: "Zerric.xyz // nexus // tech hub"
- A LAUNCHPAD linking the whole ecosystem:
  - Apps: 8trax, dualcore, ghost, pallets, retrowave, sparx, trackstars, snowsnakes, dropyourapp
  - Business: bizzy-bee.zdotllc.com, zdotllc.com, realty.zerric.xyz, zerric.com
  - Web apps: CommandCenter, GoalForge, MockupForge, WebBuilder, ZaxAppBuilder
- It's a clean link hub but essentially a list of links — no cards, no status, no descriptions.

## How we'd make it better (concrete, low-risk)
1. **App cards with one-liners** — each project gets a name, description, category (music / art / content / business / tools), and icon. Turns a link list into a portfolio.
2. **Live status badges** — each subdomain gets a small "● live" ping (we can check HTTP status). Shows it's a real nexus, not a dead list.
3. **Featured / spotlight section** — "New this week": SnowSnakes games (Food Truck Frenzy, Snow Snake), upcoming Spread Da Word.
4. **What's New feed** — a simple "recent additions" strip so the hub feels alive.
5. **Search + filter** — by category, so visitors find things fast.
6. **Design refresh** — modern, consistent, mobile-friendly, on-brand (matches Zerric's vibe; no Z-Dot or LPT branding).
7. **Meta/OG tags + a proper favicon** — so sharing zerric.xyz looks good in DMs (important for Pumpkin-style referrals).

## Delivery approach
- Single self-contained HTML page (like the games) — no framework, deployable anywhere, zero risk to existing subdomains.
- We do NOT touch any of the linked apps — we only improve the hub page itself.
- Show Zerric the before/after, then deploy when he approves.

## Why this is the right trust exercise
- It's Zerric's playground: creative, low-stakes, high-visibility.
- We prove: design taste, technical care, respecting boundaries (no branding mix, no touching his apps).
- If he's satisfied → he hands over creative control of zerric.xyz → then the business domain.
