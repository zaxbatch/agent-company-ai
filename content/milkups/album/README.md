## Scope compliance (PLAN-tracker.md sec 5)
5 tracks · each >= 90 s · built-in instruments only · **no external samples**.
Every waveform is generated by oscillators in-process (square/saw/tri, plus
noise from a fixed RNG seed), so "no external samples" holds by construction.
No third-party audio is read at any point.

## Two cuts
- **CUT A (LMMS)** — `lmms/trkNN.mmp` + `renders/lmms/trkNN.wav`.
  Layered treatment: square lead + detuned saw, saw bass, triangle pad, drums.
- **CUT B (.xm)** — `xm/trkNN.xm` + `renders/xm/trkNN.wav`.
  A real 4-channel Extended Module. The render is produced by **decoding the
  .xm file itself** (patterns + delta-encoded sample data), so if the module is
  wrong the render is silent and the build gate fails.

## Tooling
Python 3.11 · numpy · stdlib `wave`/`struct` · ffprobe/ffmpeg 5.1.8 (verification).
LMMS 1.2.2 installed at /usr/bin/lmms.

## Rebuild
```
python3 scripts/build_milkups_album.py            # build both cuts + gate
python3 scripts/build_milkups_album.py --verify-only
```
Gate = every render >= 90.0 s AND non-silent (peak > -60 dBFS). Exit 1 on failure.
