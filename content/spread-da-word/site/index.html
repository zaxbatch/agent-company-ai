🎨 BEHIND THE SCENES

How the show gets made

  • Style: South Park-style cutout animation (flat shapes, simple joints).
  • Tool: Rive (free, browser-native) for the final rigs; canvas cutout for in-browser previews.
  • Music: 8-bit chiptune generated in code — square/triangle oscillators + noise, no samples.
  • Characters: Each condiment is a rig with articulated parts (bottle, eyes, mouth, arms, legs).
  • Process: Roster → rig → scene → episode. The Snow Snake watches it all. 🐍
